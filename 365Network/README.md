# 365Network Theme

Version: 3.0.0  
Target: 365CMS v3.x.x, PHP 8.4

## Focus

Professional network theme for experts, events, companies, jobs, and content feeds.

## Modernization Highlights

- Hook/runtime hardening for 365CMS v3 workflows.
- SQL `LIMIT` usage switched to prepared placeholders in theme queries.
- Header/performance improvements with stylesheet preload and font preconnect.
- Accessibility improvements for visible focus states and keyboard navigation.
- Customizer output and settings access hardened through safe helper methods.
