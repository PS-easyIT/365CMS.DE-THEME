# buildbase Theme

Version: 3.0.0  
Target: 365CMS v3.x.x, PHP 8.4

## Focus

Construction and project delivery theme with service pages, portfolio highlights, and lead-oriented CTAs.

## Modernization Highlights

- Added v3-compatible hook registration (`init` + `cms_init`).
- Corrected Customizer key mapping for color, layout, and typography tokens.
- Hardened route/url handling and phone link sanitation in header output.
- Replaced inline template styles with reusable CSS classes.
- Added reduced-motion and ARIA improvements in navigation/search interactions.
