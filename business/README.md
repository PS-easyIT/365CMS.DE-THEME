# business Theme

Version: 3.0.0  
Target: 365CMS v3.x.x, PHP 8.4

## Focus

General corporate landing theme with clear service positioning, trust content, and conversion CTAs.

## Modernization Highlights

- Added safer asset output (preload, defer, escaped versioned URLs).
- Introduced `biz_href()` and `biz_safe_headline()` helpers for secure template output.
- Unified internal URL handling across header/home/footer templates.
- Replaced inline styles with semantic CSS utility/component classes.
- Improved keyboard focus, motion preference handling, and scroll-state styling.
