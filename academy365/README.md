# academy365 Theme

Version: 3.0.0  
Target: 365CMS v3.x.x, PHP 8.4

## Focus

Learning platform theme with course discovery, instructor highlights, and conversion-focused CTAs.

## Modernization Highlights

- Added v3-safe menu registration via `cms_init`.
- Fixed Customizer key mapping to align with `theme.json`.
- Added safe headline rendering and slug generation without legacy helpers.
- Removed inline styles in templates and moved them into reusable CSS classes.
- Improved accessibility with `:focus-visible`, ARIA state handling, and reduced-motion guards.
